# 集成控制主板 / Integrated Control Board

把 ESP32、双步进驱动、电源与 IO 集成到一块 2 层 PCB 上，替换原项目的面包板 + 杜邦线。设计严格对齐现有固件 [`esp32_tcp_stepper.ino`](../../esp32_tcp_stepper/esp32_tcp_stepper.ino) 的引脚与驱动器参数。

> 状态：设计文档（BOM 见 [`bom.md`](bom.md)，框图见 [`schematic.svg`](schematic.svg)）。KiCad/EasyEDA 工程待绘制。

## 1. 功能与指标

- 承载 ESP32-WROOM-32 模块（非开发板，直接贴模块，省空间、稳接触）。
- 两路步进驱动接口，兼容两种形态：
  - **A. 外接 DM542 类驱动器**：板子只出 STEP/DIR/ENA 信号与端子（与现固件一致，现固件注释明确写"DM542 一类"）；或
  - **B. 板载驱动座**：焊接 A4988 / DRV8825 / TMC2209 插脚模块（引脚兼容），适合小电流电机。
- 板载 DC-DC：12 V 输入 → 5 V（ESP32 + 逻辑）/ 3.3 V（可选）。
- 两路 4P 电机端子排（A+/A−/B+/B−）、电源输入端子、限位开关排针、状态 LED、USB 下载口、自恢复保险丝。

## 2. 与固件的引脚对应（关键，必须对齐）

来源：`esp32_tcp_stepper.ino` 顶部 `#define` 与 `AccelStepper` 实例化。

| 信号 | ESP32 GPIO | 说明 | 驱动器侧 |
|------|-----------|------|----------|
| 电机 X STEP | 25 | 脉冲（DM542 要求脉宽 ≥ 2.5 µs） | PUL+ |
| 电机 X DIR  | 26 | 方向（建立时间 ≥ 5 µs） | DIR+ |
| 电机 X ENA  | 27 | 使能，**高有效**（`ENABLE_LEVEL HIGH`） | ENA+ |
| 电机 Y STEP | 5  | 脉冲 | PUL+ |
| 电机 Y DIR  | 18 | 方向 | DIR+ |
| 电机 Y ENA  | 17 | 使能，高有效 | ENA+ |
| 状态 LED    | 2  | 已连接常亮 / 未连接闪烁 | — |
| 电源        | —  | 12 V 输入，板载降压到 5 V | — |

> DM542 类驱动器的 PUL−/DIR−/ENA− 通常共地接 ESP32 GND。若驱动器为 5 V 光耦输入，ESP32 的 3.3 V 逻辑可能需电平转换或确认驱动器兼容 3.3 V；建议保留 0 Ω 电阻/跳帽以便切换。

## 3. 电机行程参数（来自固件，供机械/电气校验）

- `CIRCLE_PULSES = 3200`（电机转一圈脉冲数）
- `TRAVEL_CIRCLES = 6`（像素满量程对应行程圈数）
- `MAX_SPEED = 3200×4 = 12800` 步/秒；`ACCEL = 3200×8 = 25600` 步/秒²
- `MAX_PIXEL_X/Y = 2560`（像素满量程）
- 满量程行程 = 3200 × 6 = 19200 步 ≈ 6 圈；板子与驱动器电流/电压需匹配此扭矩需求。

## 4. 电气设计要点

- **使能极性**：板上留跳帽，默认 `ENA` 高有效；若换低有效驱动器改跳帽即可（与固件 `ENABLE_LEVEL` 对应）。
- **信号完整性**：STEP/DIR 串 100 Ω 电阻 + 地到驱动器；DM542 长线建议差分或加施密特缓冲。
- **电源**：12 V 输入经自恢复保险丝 → 大容量电解（≥470 µF）+ 陶瓷去耦；MP2307/MP1584 类降压到 5 V/2 A 供 ESP32；步进驱动若板载则独立 LDO。
- **抗干扰（呼应固件优化点）**：ESP32 数字地与驱动器功率地**单点连接**（星型接地）；驱动器侧加磁珠/共模扼流；Wi-Fi 天线区域净空。
- **急停/保护**：ENA 默认上拉到生效态由 MCU 控制；可加硬件使能默认断开（掉电安全）。
- **下载与调试**：留 ESP32 下载排针（TX/RX/IO0/EN/GND）或 Type-C 转串口。

## 5. 可选扩展（见仓库 `hardware/README.md`）

- 隔离限位板：光耦隔离 endstop，接限位排针。
2. 电源/EMC 板：反接保护 + 共模扼流。
3. 编码器闭环板：ABZ → ESP32 PCNT，检测丢步。
4. 相机转接板：Maixcam 固定 + FFC。
